## 読み取り方と制約

この条件の換算ではJevの申告実費10.37ドルは掲載モデルより低い。入力が全トークンの約99.2%なので、特に入力単価が費用差へ影響する。

ただし、同じJSONを各モデルへ送ってもトークナイザーが異なるためトークン数は一致しない。実際の乗り換え費用には各社のトークン計測が必要。推論モデルの追加のthinking/reasoning tokens、回答形式や長さ、再試行、API仕様の違いも費用を変える。この表ではJevの出力トークン量を固定し、他モデル固有の推論トークンを別途推定していない。

キャッシュ可能な固定プロンプトを利用すれば費用は下がる可能性がある。ただし状態・候補は判断ごとに変わり、全入力をキャッシュ料金に置き換える比較はしていない。Batch割引は次の行動を即時に決めるゲーム操作とは用途が異なるため除外した。

Jevの10.37ドルは申告された総費用であり、公式の入力・出力単価を逆算したものではない。入力と出力の実費内訳、税・割引等はこの資料からは分からない。換算比はこの料金・トークン量の仮定に限り、Jevの一般的な価格優位性や同等性能を証明しない。
